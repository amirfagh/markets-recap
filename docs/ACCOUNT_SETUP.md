**Settings**
1. Settings → Account type → **Switch to professional → Creator**. Category: **Media/news company**
   (not a finance/advisor category). Needed for automatic posting later.
2. Contact: one brand email you actually read (sponsors will use it).
3. Turn on two-factor authentication.
4. Leave the link empty for now. Later: one link only (the newsletter).

**Pinned posts: pin exactly 3 or none.** Pinned posts take the top grid row; 1 or 2 pinned would
shift every date row. Once the intro reels exist: pin (1) "what this account is", (2) "how to read
the cards", (3) the best-performing recap.

**Highlights** (after the first stories): `How it works` · `Weekly` · `Glossary` · `Disclaimer`.
Share each day's Reels to your Story (one tap) so the account always has a story up.

## Sign-up tips
- Instagram allows up to 5 accounts in one app (Profile → your handle → Add account).
- Gmail "plus" addresses keep it to one inbox: `you+en@gmail.com`, `you+ar@gmail.com`, `you+he@gmail.com`.
- Post nothing until all three handles exist on both platforms, so the first grid row starts clean.
